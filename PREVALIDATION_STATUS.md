# Pre-validation status — v0.4.0-dev3

The formal acceptance protocol is now frozen as **HERMES-TRL4-LVP-1.0** before execution of the official 60-cell, 100-replication matrix.

Current evidence is still **pre-validation**. Existing development and pilot runs do not become formal evidence retroactively. The q=1 J=18/N=17 pilot remains a development check because it used 10 replications rather than the frozen 100-replication requirement.

Formal TRL4 evidence still requires:

1. a locked environment including the PyWavelets dependency required by q=2/q=3;
2. execution of all 60 published benchmark cells with 100 replications each;
3. automatic evaluation under the frozen mean and variance compatibility criteria;
4. any pre-registered confirmatory batches required by failed cells;
5. all engineering release gates;
6. independent second-operator reproduction.

The generalized Hermite/GHP branch remains excluded from this baseline.
